# Fed10 Releases

Public distribution channel for the Fed10 macOS menu-bar app.

- **Latest download:** the newest `Fed10-<version>.dmg` under [Releases](https://github.com/Fed10/releases/releases/latest).
- `appcast.xml` is the Sparkle update feed the installed app polls (served over HTTPS via raw.githubusercontent.com). Never edit it by hand — `scripts/release.sh` in the app repo regenerates and signs it.

Requires an Apple Silicon Mac (arm64) on macOS 13 or later.
